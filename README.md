## Sobre

Sou desenvolvedor full stack e gosto de transformar processo de negócio em software que funciona no dia a dia: sistemas de gestão (ERP), APIs que outros sistemas consomem e automações que tiram trabalho manual da frente.

Meu foco hoje:

- **Back-end** — APIs REST com autenticação, validação e testes
- **Front-end** — interfaces simples, rápidas e acessíveis
- **Automação** — scripts em Python que coletam, tratam e gravam dados

`ERPs` · `APIs REST` · `Automação` · `TypeScript` · `Node.js` · `Python` · `Testes` · `CI/CD`
